# 忌口过滤规则词表

`scripts/planner.py` 对**餐品名称**和**tags** 做子串匹配，命中即剔除。
因此忌口词要选「一定会出现在菜名里」的那类词，避免误伤。

## 一、预设忌口 → 推荐关键词

| 用户选的忌口 | 传给 planner 的 avoid 关键词 | 说明 |
| --- | --- | --- |
| 不吃辣 | `辣`, `香辣`, `麻辣`, `藤椒` | 「麦香鸡」不含辣，不会被误伤 |
| 不吃洋葱 | `洋葱` | |
| 不吃酸 | `酸`, `柠檬`, `番茄`, `番茄酱` | 「酸」过宽时会误伤酸奶/酸黄瓜，可按需精简 |
| 减脂低卡 | `炸`, `薯条`, `派`, `冰淇淋`, `圣代`, `麦旋风`, `可乐`, `糖` | 减脂是**强度最高**的忌口，注意别把主食全过滤光 |
| 不吃油炸 | `炸`, `薯条`, `鸡排`, `鸡块`, `鸡柳`, `脆` | |
| 儿童清淡 | `辣`, `芥末`, `黑椒`, `咖啡` | |
| 不吃生菜 | `生菜`, `沙拉` | |
| 清真/不吃猪肉 | `猪`, `培根`, `火腿`, `早餐猪肉` | 注意「火腿」可能出现在早餐系列 |
| 海鲜过敏 | `鱼`, `虾`, `海` | 「麦香鱼」会被剔除 |
| 坚果过敏 | `坚果`, `花生`, `杏仁` | |
| 不吃蛋奶 | `蛋`, `奶`, `芝士`, `酸奶` | 注意会剔除牛奶饮品 |
| 素食 | `鸡`, `牛`, `猪`, `鱼`, `虾`, `培根` | **极易把主食全部剔除**，命中后会走降级模式 |
| 不吃香菜 | `香菜` | |

## 二、口味偏好 → prefer 关键词

| 用户选的偏好 | prefer 关键词 |
| --- | --- |
| 偏爱炸鸡 | `炸鸡`, `鸡翅`, `鸡块`, `鸡排`, `脆鸡`, `麦辣鸡` |
| 偏爱汉堡 | `堡` |
| 偏爱甜品 | `派`, `圣代`, `甜筒`, `冰淇淋`, `麦旋风` |
| 偏爱饮品 | `可乐`, `雪碧`, `咖啡`, `奶茶`, `牛奶`, `果汁` |
| 偏爱牛肉 | `牛` |
| 偏爱鸡肉 | `鸡` |
| 无偏好 | 留空数组 |

偏好是**加分项**不是过滤项，宁可宽一点也不要漏。

## 三、执行建议

1. 先拿菜单，再决定关键词：如果某个忌口词会把主食区过滤到只剩不到 3 个 SKU，**降级为提示用户放宽**，由用户决定是否保留。
2. 过滤结果一定要告诉用户。planner 输出的 `dropped` 字段按原因分组，直接展示给用户「因为 XXX 剔除了 N 个餐品」，这是信任感的关键。
3. 「忌口贵族」（忌口 ≥ 3 项）命中后，如果 `feasible=false`，必须按 GPT 建议给出**预算缺口金额**和**最低可行方案**，而不是只说「无法搭配」。
4. 用户自定义忌口词走同样机制：直接把用户原话里去掉「不吃」「忌口」「不要」后的核心词，放进 `avoid`。例如「不要酸黄瓜」→ `avoid: ["酸黄瓜"]`。
5. 避雷清单是**跨永久**的：用 `profile.py blacklist add` 落盘后，每次 `collect` 都会自动带出来。
